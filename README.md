# codealpha_tasks
A modern and responsive task management web application designed to help users create, organize, and manage their tasks efficiently.

🚀 Features

👤 User registration & login
🛍️ Products loaded from MySQL
🔍 Product search
🏷️ Category filtering
🛒 Database-based shopping cart
❤️ Wishlist
📦 Place orders
📋 Order history
👨‍💼 Admin dashboard
➕ Add products
✏️ Edit products
🗑️ Delete products
📊 Manage orders
